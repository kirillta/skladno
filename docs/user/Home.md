# Skladno

Skladno is a local-first writing workspace for technical authors. It helps authors develop, review, fact-check, translate, and prepare Articles while keeping every change under their control.

AI output never silently changes an Article. The author reviews each Proposal, and every accepted change creates an immutable Revision.
